## Pemeriksaan sebelum pengumpulan

- [x] Tepat satu initial node dan minimal satu activity final node pada setiap diagram; tidak ada action yang terputus dari alur.
- [x] Setiap decision mempunyai guard pada semua alur keluar; guard saling lepas dan menutup kemungkinan yang relevan.
- [x] Setiap cabang decision kembali melalui merge atau bermuara ke activity final node dengan keadaan akhir yang jelas.
- [x] Fork selalu berpasangan dengan join; proses paralel disatukan oleh join, bukan merge.
- [x] Setiap action berada pada swimlane aktor yang melakukannya; respon sistem berada pada swimlane Sistem.
- [x] Setiap action tertelusur ke langkah tabel skenario Pertemuan 5 dan namanya sama dengan bunyi langkah sumber.
- [x] Include digambar sebagai action wajib pada alur utama (`Periksa Ketersediaan` pada peminjaman; `Periksa Kondisi Peralatan` pada pengembalian).
- [x] Extend digambar sebagai cabang bersyarat dengan condition `[ya, memilih cetak]`.
- [x] `Periksa kelengkapan aksesori peralatan` diberi keterangan unsur proses baru.
- [x] Collaboration tidak digambar sebagai action atau swimlane.
- [x] Kepala Laboratorium hanya muncul pada Activity Lihat Laporan Peminjaman.
